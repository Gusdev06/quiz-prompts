# BlackBox A.I — rebuild scaffold

Generated by `quiz-cloner` on 2026-05-14 from `https://blackbox.xquiz.io/`.

This is a **starter scaffold**, not a finished product. The conversion mechanics (copy, pulse CTA, narrow column, slate palette, green button) are wired up; the visual polish (exact images per step, score-circle styling, offer-page testimonial cards) is left for you to refine.

## Get running

```bash
cd rebuild
npm install     # or pnpm install / bun install
cp .env.example .env.local   # edit if you have a Meta Pixel ID
npm run dev
```

Open http://localhost:3000.

## Stack

- **Next.js 15 (App Router)** + React 19
- **Tailwind v3.4.19** — matches the original (`v3.4.19` confirmed in the source CSS banner)
- **Zustand** for step state
- **No animation library** — pure CSS keyframes (`pulse`, `entry`) live in `tailwind.config.ts`
- **No `next/font`** — Poppins is self-hosted from `public/assets/fonts/` (woff2 files captured from the original)

## What's not done — your call

- ❌ **Per-step images** — `lib/content.ts` doesn't reference specific `imageUuid` values. Add them per step from `public/assets/shared/` (the original mapping is in `../assets/manifest.json` if you need it). For each choice or hero image, set `imageSrc` on `AnswerCard` or render an `<img>` directly.
- ❌ **Step 11 score logic** — hardcoded 89% (matches the original). If you want it dynamic, derive from `quizStore.getState().answers`.
- ❌ **Step 13 layout polish** — the offer page is functional but needs the testimonial card images, guarantee badge, and the "ACESSE AGORA MESMO" graphic to look like the original
- ❌ **Image compression** — some of the captured webp files are 4–6 MB. Run through `cwebp -q 75` or use Next.js `<Image>` for automatic optimization
- ❌ **No tests** — add when you commit to ownership of the codebase

## On the captured Meta Pixel ID

The original page exposed pixel ID `1020430209846628` (the seller's). It's **not** baked into this rebuild. Set your own via `NEXT_PUBLIC_FB_PIXEL_ID` in `.env.local`.

## On versioning

The original was built on Tailwind 3.4.19 and a (presumably) recent Next.js. This scaffold targets **Next 15 + Tailwind 3.4** for fidelity. You can upgrade to Tailwind 4 / Next 16 later — none of the patterns here block that. Run `npx @next/codemod@latest` when you do.

## Deploying

It's a vanilla Next.js app. `vercel` or `vercel --prod` from this directory just works. Set `NEXT_PUBLIC_FB_PIXEL_ID` and `NEXT_PUBLIC_CHECKOUT_URL` in the Vercel project's environment variables.

## What this scaffold is NOT

- Not a clone of the XQuiz platform itself (that's a multi-tenant SaaS)
- Not legally vetted — clone responsibly; the original's `robots.txt` was `Disallow: /`
